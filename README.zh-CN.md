# CodexQuota 额度小组件

Mac 菜单栏与桌面悬浮小工具，查看当前 Codex 账号的额度和重置时间。独立社区项目，非 OpenAI 官方产品。

## 能做什么

- 显示短时额度（账号提供时）、每周额度、重置倒计时和积分。
- 点击进度条展开，移开鼠标自动收起；可拖动、锁定、隐藏。
- 每 60 秒刷新，也能手动刷新。
- 保存本机账号快照；以前账号的数字标记为历史数据。
- 从本地 Codex 会话日志提取项目路径与 Token 数字，显示近期项目占比。它不是账单，也不是各项目消耗订阅额度的准确比例。
- 开源副本含深海蓝、暖琥珀、薄荷绿三种配色，不含原自用版的人物图片。

## 使用条件

macOS 14 或更新版本；已安装 Apple Command Line Tools；已安装 Codex 并登录 ChatGPT 账号。无需安装 Python、Node 或完整 Xcode。

在项目目录打开终端：

```sh
zsh scripts/build-app.sh
open build/CodexQuota.app
```

若缺少 Apple 编译工具，先运行 `xcode-select --install` 并按系统提示安装。

构建仅在项目的 build 目录生成应用，不自动安装、不替换桌面旧版。需要安装时，可退出旧版后在 Finder 手动复制到你选择的位置。开源副本使用独立设置标识，不会继承原自用版账号台账和皮肤。

程序目前查找应用目录中的 ChatGPT/Codex 内置命令，以及 `/opt/homebrew/bin/codex`、`/usr/local/bin/codex`。其他安装位置、定制 Codex 数据目录尚不支持。账号切换请在 Codex 内完成。

## 隐私与限制

详见 [PRIVACY.md](PRIVACY.md)。会读取本地会话日志文件，但统计只使用项目路径和 Token 数字；没有独立遥测上传功能。Codex 子进程查询账号额度可能连接 OpenAI 服务。

应用只有本机临时签名，未做 Apple 公证；首次打开可能出现系统提示。目前没有公开安装包或自动更新功能。界面为中文，英文说明不代表界面已经英文化。

## 自检

```sh
zsh scripts/check.sh
```

检查构建、签名、应用信息和合成日志的增量解析。需要 macOS 图形会话。不能替代真实账号的额度读取与日常使用验收。
